1. What is JSX, and why is it used?
Answer: JSX is a syntax that lets you write HTML inside JavaScript. It’s used in React to easily describe how the UI looks.

2. What is the difference between State and Props?
Answer:
State: Data that belongs to a component and can change over time.
Props: Data passed from a parent component to a child, read‑only.

3. What is the useState hook, and how does it work?
Answer:
useState is a React hook to create state inside a function component.
It gives you two things: the current value and a function to update it.

4. How can you share state between components in React?
Answer: Lift the state up to a common parent, then pass it down as props to the child components.

5. How is event handling done in React?
Answer: Events are written in camelCase and passed as functions.
